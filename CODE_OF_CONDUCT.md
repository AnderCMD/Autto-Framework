# Code of Conduct · Código de conducta

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Este proyecto sigue el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

**In short / En resumen:** be respectful, welcoming and constructive. Harassment or discrimination of any kind is not
tolerated. / Sé respetuoso, acogedor y constructivo. No se tolera el acoso ni la discriminación de ningún tipo.

Report unacceptable behaviour privately to the maintainers through GitHub
([@AnderCMD](https://github.com/AnderCMD)). / Reporta comportamientos inaceptables de forma privada a los mantenedores
a través de GitHub.
