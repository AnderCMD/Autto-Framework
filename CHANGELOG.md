## [Unreleased]

### Added

- Cucumber 8 + JUnit Platform 6 + Selenium 4.50 + Appium 10 template targeting Java 27.
- Screaming architecture: one folder per business feature (`features/<feature>`) holding pages, steps and models.
- Layered configuration (`autto.properties` → `environments/<env>.properties` → `AUTTO_*` env vars → `-D` properties).
- Local (Chrome, Firefox, Edge, Safari), remote (Selenium Grid / cloud vendors) and Appium (Android / iOS) targets.
- Extent Spark report generated by a custom, parallel-safe Cucumber plugin: dashboard, timeline, tags, devices,
  authors, failures-only report and JSON archive.
- Evidence: screenshots (on failure or every step), MP4 video recording without external tools, page source,
  browser console logs (WebDriver BiDi) and arbitrary attachments.
- Cucumber HTML, JSON, JUnit XML, NDJSON and rerun outputs.
- GitHub Actions: framework checks, cross-OS × cross-browser E2E matrix, nightly Selenium Grid regression.
- Docker Compose Selenium Grid, Maven Wrapper, Dependabot.
- Documentation in English (`docs/en`) and Spanish (`docs/es`).
